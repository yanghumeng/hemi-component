我有一个功能需求

框架：react16.8+ts

UI 框架：@yds/components(魔改 antd3.x)

功能：类似于一个画图工具

详细需求： 1、工具上面是工具条，工具条上有多个工具分别是：画点（选择）、回退（撤销）、重置、保存 2、工具条中间是画布，画布上可以画点，每个点就是一个圆，圆的半径是 10px，颜色是红色 3、工具下面分为左中右三部分，左边是预留区，中间是切换图片的缩略图，右边也是预留区域 4、中间的详细区域是画布的详细信息，包括： 1）可以放大缩小 2）可以移动 3）可以放大或者缩小后，再标注点的位置 4）点击选择时才能开始标注点的位置 5）点击回退时就撤销上一次画的点，点一次撤销一次 6）点击重置时就清空画布，回到初始状态 7）点击保存时就保存当前画布上的所有点，保存的格式是 json 8）保存的 json 格式如下： { "points": [ {"x": 100, "y": 100}, {"x": 200, "y": 200} ] } 9）点的大小不随着画布进行放大缩小，但是位置要随着画布的放大缩小而变化 10）点的位置数据要根据图片的真实大小数据来计算 11）放大的位置要以鼠标位置为中心进行放大 12）鼠标进入画布滚动鼠标滚轮可以放大缩小，但是页面不允许滚动 13）以图片的左上角为 0，0 点
